03 / How the launch works

A clear path on-chain.

ONRC launched with Meteora's Dynamic Bonding Curve and a USDC quote token. The configuration sets a graduation threshold and a subsequent DAMM v2 migration.

I.

Bonding curve

The initial ONRC / USDC pool uses a Meteora Dynamic Bonding Curve with a 0.30% base trading fee.

II.

750 USDC threshold

The pool is configured with a 750 USDC quote-reserve graduation threshold. Graduation depends on the pool reaching the required conditions.

III.

DAMM v2 migration

After graduation, the configuration targets Meteora DAMM v2 with 100% of migrated liquidity allocated to permanent LP locking.

Liquidity lock percentages describe the launch configuration. Actual DAMM v2 migration and locking happen only after graduation and must be checked on-chain. ONRC is a meme token and makes no promises of returns.
